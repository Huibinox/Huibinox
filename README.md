# Guibin Huang

I’m an Immunochemistry Analyst (Researcher II) at WuXi AppTec in Shanghai. I work on whole-blood and PBMC flow cytometry, from sample preparation and acquisition through analysis and reporting. I also contribute to multicolour panel design and method development, optimisation, and validation.

Previously, I worked on ICU-linked translational research at Trinity College Dublin and St. James’s Hospital, with a focus on clinical samples and extracellular vesicle biomarkers.

## Projects

- **[Express7 CytoSummary](https://github.com/Huibinox/express7-cytosummary)** · Python and SQLite desktop tool for organising flow cytometry results by project, panel, and run, with Excel summaries and validation statistics.
- **[Sample Stability 96h](https://github.com/Huibinox/sample-stability96)** · Tracks sample stability deadlines to help plan instrument runs and flag overdue samples.
- **[Assay File Library](https://github.com/Huibinox/assay-file-library)** · Shared library for finding and updating assay records by project, with version history and expiry reminders.
- **[Folder PDF Printer](https://github.com/Huibinox/folder-pdf-printer)** · Scans multiple folders so PDFs can be selected and printed as a batch.
